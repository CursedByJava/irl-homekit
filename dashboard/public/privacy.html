IRL Homekit Studio

IRL Homekit Studio is a private control panel that one streamer runs on their own home PC to manage their own Twitch, Kick and YouTube channels: reading and sending chat, changing the stream title and category, and seeing whether each channel is live. It is not a public service and there is no way to sign up.

Privacy policy

Who uses it. Only the owner of the PC it runs on. Sign-in is protected by a username and password.

What it accesses. When the owner connects a platform, the app receives an access token for that owner's account with only these permissions: read and send chat, read and update the channel's title and category, and read live status. For YouTube it uses the YouTube Data API to read the owner's live broadcast, update its title, and read and post live chat messages.

Where data is stored. Tokens are stored only in a file on the owner's own PC. Chat messages are kept in memory for display and are never written to disk, sold, shared or sent anywhere else.

Third parties. Data goes only between the owner's PC and the platform it belongs to (Twitch, Kick, Google/YouTube). Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. The owner can disconnect at any time from each platform's connected-apps settings (for Google: myaccount.google.com/permissions), which revokes the token immediately.

Contact. Questions: contact the owner of this domain.
